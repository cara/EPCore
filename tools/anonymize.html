Lab-System wählen

Wählen Sie das Aufnahmesystem, mit dem die Daten erstellt wurden. Die Erkennung der Patientenverzeichnisse hängt davon ab.

Quellordner auswählen

Wählen Sie den Ordner, der die Patienten- bzw. Studienverzeichnisse enthält. Verzeichnisse, die eine Markierungsdatei des gewählten Lab-Systems enthalten, werden als Patientenverzeichnis erkannt. Beispiel: Backup/.

Zuordnung prüfen

Patientenverzeichnisse erhalten Pseudonyme. Andere Verzeichnisse werden unverändert übernommen. Sensible Dateien (siehe Markierung) werden ausgeschlossen.

Original Anonymisiert

Anonymisieren und speichern

"In Ordner speichern" schreibt anonymisierte Dateien direkt in einen von Ihnen gewählten Ausgabeordner (Chrome/Edge ab Version 86). Ansonsten erzeugen Sie ein ZIP zum Download.

Protokoll

Skript offline verwenden

Sie können dieses Anonymisierungs-Skript als einzelne, eigenständige HTML-Datei herunterladen und später ohne Internetverbindung lokal im Browser öffnen.

Quellcode: tools/anonymize-classic.html

Datenschutz: Diese Seite läuft komplett lokal in Ihrem Browser. Es werden keine Daten an einen Server geschickt – auch nicht zum Anonymisieren. Sie können die Datei anonymize_rhythmia.html herunterladen und ohne Internetverbindung öffnen. Schließen Sie das Browser-Fenster, dann sind alle eingelesenen Daten weg.
Wichtig: Diese Software ist ein Hilfsmittel und ersetzt nicht die manuelle Prüfung. Verifizieren Sie nach der Anonymisierung mit einem Hex- oder Texteditor (oder durch erneutes Einlesen mit der Vorschau-Funktion), dass keine personenbezogenen Daten mehr enthalten sind. Geometrie- und Voltage-/Aktivierungswerte selbst bleiben unverändert.
