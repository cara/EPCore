CARTO 3 Daten Anonymisierer

Entfernt Patientendaten aus Biosense Webster CARTO 3 Exporten (.zip Archive oder einzelne .mesh Dateien).

Datenschutz: Alles läuft lokal im Browser. Es werden keine Daten an einen Server geschickt. Die Datei kann auch offline geöffnet werden.
Wichtig: CARTO-ZIP-Archive enthalten oft mehrere Dateien (.mesh, .txt, .xml, ECG-Exports, …). Diese Seite anonymisiert alle textbasierten Dateien im Archiv. Binärdaten werden unverändert übernommen. Nach der Anonymisierung manuell verifizieren.
